# Домовой Наум

**Домовой Наум** — Telegram-бот для взрослых и пожилых людей. Он отвечает текстом, понимает голосовые сообщения, анализирует фотографии, помогает с бытовыми вопросами, едой, растениями и мягко поддерживает в тревожные моменты. По здоровью бот даёт только общую бытовую информацию: не ставит диагнозы, не назначает лекарства и при опасных симптомах советует обратиться к врачу или вызвать скорую.

## Возможности MVP

- Текстовый чат в образе доброго домашнего помощника Наума.
- Голосовые сообщения: скачивание voice из Telegram, расшифровка через OpenAI speech-to-text, текстовый ответ и голосовой ответ через OpenAI text-to-speech.
- Фото: анализ еды, растений, цветов, насекомых, бытовых предметов, продуктов, ошибок на экране и состояния блюда/растения.
- Профиль пользователя: имя, возраст, город/станица, болезни, лекарства, аллергии, имена детей, Telegram ID ребёнка, интересы.
- Тревожные фразы: спокойный ответ пользователю и уведомление родственнику, если указан `child_telegram_id`.
- История диалога в SQLite или PostgreSQL.

## Команды

- `/start` — знакомство с Наумом.
- `/help` — что умеет бот.
- `/profile` — показать сохранённый профиль.
- `/set_profile` — заполнить профиль в диалоге.
- `/reset` — очистить историю разговора, не удаляя профиль.

## Как создать Telegram-бота

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте команду `/newbot`.
3. Задайте имя, например `Домовой Наум`.
4. Задайте username, который заканчивается на `bot`, например `domovoy_naum_bot`.
5. Скопируйте токен Bot API и положите его в переменную `TELEGRAM_BOT_TOKEN`.

## Переменные окружения

Скопируйте пример и заполните значения:

```bash
cp .env.example .env
```

Файл `.env`:

```env
TELEGRAM_BOT_TOKEN=123456:telegram-token
OPENAI_API_KEY=sk-...
OPENAI_TEXT_MODEL=gpt-4o-mini
OPENAI_VISION_MODEL=gpt-4o-mini
OPENAI_STT_MODEL=whisper-1
OPENAI_TTS_MODEL=tts-1
DATABASE_URL=sqlite+aiosqlite:///./naum.db
DEFAULT_CHILD_TELEGRAM_ID=
```

### База данных

Для MVP проще использовать SQLite:

```env
DATABASE_URL=sqlite+aiosqlite:///./naum.db
```

Для Docker Compose с PostgreSQL используйте:

```env
DATABASE_URL=postgresql+asyncpg://naum:naum_password@postgres:5432/naum
```

## Локальный запуск

Требуется Python 3.11+.

```bash
cd domovoy-naum
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните .env
python bot.py
```

После запуска напишите своему боту в Telegram команду `/start`.

## Запуск через Docker

```bash
cd domovoy-naum
cp .env.example .env
# заполните .env и для PostgreSQL поставьте:
# DATABASE_URL=postgresql+asyncpg://naum:naum_password@postgres:5432/naum
docker compose up --build
```

Если хотите запускать Docker только с SQLite, можно удалить сервис `postgres` из `docker-compose.yml`, убрать `depends_on` и указать:

```env
DATABASE_URL=sqlite+aiosqlite:////app/data/naum.db
```

## Как проверить текст

1. Запустите бота.
2. Напишите `/start`.
3. Отправьте обычный вопрос, например: `Что приготовить из картошки и яйца?`.
4. Бот должен ответить коротко и по-доброму.

## Как проверить голосовые

1. Убедитесь, что в `.env` заполнены `OPENAI_API_KEY`, `OPENAI_STT_MODEL` и `OPENAI_TTS_MODEL`.
2. Отправьте боту voice message в Telegram.
3. Бот должен написать: `Я расслышал: ...`, затем дать ответ текстом и отправить голосовой ответ.
4. Если ключи или сеть недоступны, в логах будет понятная ошибка, а пользователь увидит: `Сейчас не получилось обработать, попробуйте ещё раз чуть позже.`

## Как проверить фото

1. Убедитесь, что заполнены `OPENAI_API_KEY` и `OPENAI_VISION_MODEL`.
2. Отправьте фото растения, блюда, продукта или бытового предмета.
3. Можно добавить подпись: `Что с листьями?` или `Можно ли это есть?`.
4. Наум ответит: что видно, что это может быть, что делать дальше и когда нужна осторожность.

## Как указать Telegram ID родственника

Есть два способа:

1. **Через профиль пользователя.** Пользователь отправляет `/set_profile` и на вопрос `Telegram ID ребёнка?` вводит числовой Telegram ID родственника.
2. **Через значение по умолчанию.** Администратор указывает в `.env`:

```env
DEFAULT_CHILD_TELEGRAM_ID=123456789
```

Тогда новый профиль получит этот ID автоматически. Родственник должен заранее открыть чат с ботом и нажать `/start`, иначе Telegram может не позволить боту написать первым.

## Тревожные сообщения

Если пользователь пишет фразы вроде `мне очень плохо`, `я упала`, `не могу встать`, `давление 190`, `не хочу жить`, `сильная боль в груди`, `тяжело дышать`, бот:

1. спокойно отвечает пользователю;
2. советует срочное безопасное действие, включая 112/103 при опасных симптомах;
3. отправляет уведомление родственнику, если в профиле есть `child_telegram_id`.

Пример уведомления:

> Наум заметил тревожное сообщение от мамы: ‘мне плохо, давление 190’. Лучше связаться с ней/ним сейчас.

## Важные ограничения

- Наум не заменяет врача, психолога или экстренные службы.
- Наум не ставит диагнозы, не назначает лекарства и не меняет дозировки.
- При боли в груди, сильной одышке, признаках инсульта, потере сознания, давлении выше 180/120, сильной боли, крови, травме после падения или мыслях о самоповреждении нужно обращаться за срочной помощью.
