# Домовой — ИИ-помощник для родителей

**Домовой** — семейный Telegram-ассистент для родителей. Он помогает с режимом дня, питанием, развитием ребёнка, бытовыми напоминаниями и спокойными сценариями поведения в сложных ситуациях.

## Главная идея

Не медицинский бот и не сухой справочник. Это домашний помощник, который каждый день снижает хаос в семье:

- что приготовить ребёнку и всей семье;
- как выстроить режим дня;
- чем занять ребёнка дома;
- как спокойно пройти истерику, отказ от сна или еды;
- что купить, не забыть, запланировать;
- как распределить семейные задачи.

## MVP

Первая версия должна работать в Telegram и поддерживать основные режимы:

1. **Питание**
   - меню на день;
   - рецепты по возрасту;
   - список покупок;
   - блюда из того, что есть дома;
   - семейный ужин: ребёнку + взрослым.

2. **Режим дня**
   - сон;
   - прогулки;
   - еда;
   - садик / школа;
   - занятия;
   - напоминания.

3. **Развитие**
   - игры по возрасту;
   - занятия без гаджетов;
   - речь, моторика, логика;
   - идеи на 15/30/60 минут.

4. **Поведение**
   - истерика;
   - не хочет спать;
   - не хочет есть;
   - адаптация к саду;
   - ревность;
   - спокойные фразы для родителей.

5. **Семейные задачи**
   - напоминания;
   - список покупок;
   - дела по дому;
   - календарь ребёнка.

## Ограничения безопасности

Бот не ставит диагнозы, не назначает лечение, не заменяет врача, психолога или педагога. При медицинских симптомах, травмах, температуре, аллергии, подозрении на опасное состояние бот рекомендует обратиться к врачу или вызвать экстренную помощь.

## Стек первой версии

- Python 3.11+
- aiogram 3
- OpenAI API
- SQLite для MVP
- APScheduler для напоминаний
- python-dotenv
- Railway / Render / VPS для деплоя

## Переменные окружения

DATABASE_URL=sqlite+aiosqlite:///domovoy.db

## Цель MVP

Собрать работающего Telegram-бота, который:

- принимает текстовые сообщения;
- понимает контекст семьи;
- задаёт короткие уточнения, если не хватает данных;
- даёт практичные ответы;
- сохраняет базовый профиль семьи;
- умеет создавать простые напоминания;
- имеет безопасный системный промпт.
